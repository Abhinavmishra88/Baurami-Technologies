# Baurami Technologies 🚀

### Innovate. Build. Grow.

Baurami Technologies is a responsive business website developed to showcase digital services, technology solutions, and projects. It provides a modern, user-friendly interface where visitors can explore company information, discover services, view projects, and contact the business.

The platform also includes Firebase Authentication with email verification, password recovery, and a protected user dashboard.

## 🌐 Live Website

**[Visit Baurami Technologies](https://baurami-technologies.vercel.app/)**

## ✨ Features

- **Responsive Design** – Compatible with desktop, tablet, and mobile devices.
- **Modern Homepage** – Professional layout with a hero section and company highlights.
- **About Section** – Information about the company.
- **Services Section** – Showcase of digital and technology services.
- **Projects Section** – Display of projects and work.
- **Firebase Authentication** – Email and password registration and login.
- **Email Verification** – Email verification during registration.
- **Password Recovery** – Reset forgotten passwords.
- **User Dashboard** – Protected dashboard for authenticated users.
- **Session Management** – Firebase authentication state management.
- **Contact Form** – Frontend form validation.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Abhinavmishra88/Baurami-Technologies.git
```

### 2. Open the Project

```bash
cd Baurami-Technologies
```

### 3. Configure Firebase

1. Open the Firebase Console.
2. Create or select your Firebase project.
3. Enable Email/Password authentication.
4. Configure your Firebase web application.
5. Update `js/firebase-config.js` with your Firebase web configuration.

### 4. Run the Website

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
